## 為什麼結構化資料裡**刻意沒有** `aggregateRating`

Google 的評論摘要政策要求：標記的評價必須來自**頁面上實際可見的評論**。
自行在自家網站標註「5.0 分、48 則評論」屬於自我評價，不符規範，可能被視為不實標記而遭人工處分。

因此星等以**文字呈現並連結到 Google 地圖**，不寫入 JSON-LD。
若日後要在本頁放真實的顧客評論（有授權、有原文），才可考慮加入。
